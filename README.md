The **kirby-fitzpatrick-silent-author-test** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Core Patterns

- **Silent Author Test**: The Silent Author Invariant: write technical artifacts assuming the author will never be available to clarify or explain.
- **Practical Application**: Production library documentation, runbooks, and critical path comments.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
